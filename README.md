# 12306 智能抢票系统

自动抢购12306火车票的Python程序。

## 功能特点

- 支持账号密码登录和扫码登录
- 自动查询余票并抢票
- 支持多日期、多车次轮询
- 支持连座抢票（尽量选择相邻座位）
- 支持成人票和儿童票

## 默认配置

- **路线**: 北京 -> 陇西
- **车次**: D29 / Z151
- **日期**: 2026-02-11 / 2026-02-13
- **票数**: 3张 (2成人 + 1儿童)

## 安装

```bash
# 安装依赖
pip install -r requirements.txt
```

## 使用方法

### 正常抢票模式

```bash
python main.py
```

程序会引导你：
1. 选择登录方式（推荐扫码登录）
2. 输入乘客信息（姓名、身份证号、手机号）
3. 选择座位类型优先级
4. 确认信息后开始自动抢票

### 测试模式（仅查询，不需要登录）

```bash
python main.py --test
```

## 注意事项

1. **登录方式**：推荐使用扫码登录，账号密码登录可能需要验证码
2. **抢票时间**：建议在开票时间前几分钟启动程序
3. **网络要求**：需要稳定的网络连接
4. **支付**：抢票成功后请尽快在12306官网完成支付
5. **合法使用**：本程序仅供学习交流，请勿用于非法用途

## 自定义配置

如需修改默认配置，可以编辑 `main.py` 中的以下部分：

```python
# 设置路线
grabber.set_route("北京", "陇西")

# 设置日期
grabber.set_dates(["2026-02-11", "2026-02-13"])

# 设置车次
grabber.set_trains(["D29", "Z151"])

# 设置连座人数
grabber.set_consecutive_count(3)
```

## 常见问题

### Q: 登录失败怎么办？
A: 建议使用扫码登录。如果仍然失败，可能是12306临时限制，请稍后再试。

### Q: 一直查不到票怎么办？
A: 1) 检查日期是否在预售期内 2) 确认车次和站点名称正确 3) 该车次可能确实无票

### Q: 抢到票后如何支付？
A: 登录12306官网或APP，在"未完成订单"中完成支付。
